# Method Notes

This directory records the scope of the comparison. The benchmark is not a
full reimplementation of the two papers. It is a controlled proxy experiment
that tests a regime outside their easiest success case: multiple low-loss
regions with thin valleys and high-energy barriers induced by dataset
complexity.

Files:

- `arxiv_baselines.md`: source-grounded baseline summary.
- `claim_evidence_matrix.md`: what the experiment is allowed to claim.
