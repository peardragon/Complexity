# Eq. (50) Quadrature Smoke Run

the corrected Eq. (50) theory outputs on 2026-06-16.

reference normalization, then measures one-radius coarse and fine timings used
to estimate the retained full runs.

are stored under the stage `raw_outputs/` directory.
