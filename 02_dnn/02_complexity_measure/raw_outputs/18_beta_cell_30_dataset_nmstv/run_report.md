# Complexity subset report: 18_beta_cell_30_dataset_nmstv

This directory contains the NMSTV summary tables for the public 18-beta / 30-dataset production subset.

- selection rule: retained 18 beta cells x 30 datasets
- metric: normalized multiscale total variation (NMSTV), used as dataset complexity
- retained tables: cell-level, dataset-level, multiscale, and ordering-pair CSVs
