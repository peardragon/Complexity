# MANIFEST

This package creates an instruction layer for:

```text
02_dnn/08_mnist
```

It does not execute experiments by itself. It supplies:

- stage-level README files;
- stage-level START_PROMPT files;
- acceptance checklists;
- master GOAL prompts;
- config templates;
- shell scripts for launching Codex.

Use `prompts/MASTER_GOAL_MODE_START_PROMPT.md` to start from chat or non-interactive Codex.
